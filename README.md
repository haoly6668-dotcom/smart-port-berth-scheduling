# 智慧港口泊位智能调度系统

大学生创新创业训练计划（大创）项目可视化系统。面向集装箱港口的泊位分配问题，根据船舶吃水、船长、TEU、到港时间和优先级，结合各泊位的水深、长度、岸桥数量与作业效率，自动计算泊位分配与作业时间，并以可视化大屏实时展示调度结果。

## 功能

- **泊位管理**：4 个默认泊位（T1–T4），可在线增删和编辑每个泊位的最大吃水、岸桥总数、作业效率和泊位长度，也可一键恢复默认配置
- **船舶到港计划**：添加 / 删除待靠泊船舶，记录船名、船长、吃水、TEU、到港时间和优先级（高 / 普通 / 低）
- **智能调度算法**：
  - 按优先级权重和到港时间排序待调度船舶
  - 硬约束过滤：船舶吃水（含 1 米安全余量）和船长不得超过泊位能力
  - 按 TEU 动态分配岸桥数量，并针对大船 / 高优先级场景做泊位偏好加权，以等待时间 + 作业时间为成本择优分配泊位
  - 无法靠泊时给出原因（吃水过大 / 船身过长 / 无可用泊位）
- **可视化大屏**：
  - 泊位能力对比图、泊位作业负载占比、船舶等待时间趋势（Chart.js）
  - 调度结果甘特图与泊位分配明细表：靠泊泊位、起止时间、分配岸桥数
  - 统计指标：总在港时间、泊位利用率、最大完工时间
  - 运营快报（船舶总数、总 TEU、高优先级船舶、总岸桥数）、港口负荷指数、基于正弦曲线的实时潮汐模拟、实时时钟

## 技术栈

- 后端：Python Flask + Flask-CORS，内存数据存储，提供 REST API
- 前端：原生 HTML / CSS / JavaScript，Chart.js 图表，Font Awesome 图标
- 调度核心：`app.py` 中的 `schedule_ships` 函数（约束过滤 + 成本择优）

## 运行方式

```bash
pip install -r requirements.txt
python app.py
```

浏览器打开 http://127.0.0.1:5000 即可使用：先在左侧查看 / 设置泊位，中间添加船舶到港计划，再点击「运行智能调度」查看右侧的分配结果。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/berths` | 获取当前泊位配置 |
| PUT | `/api/berths` | 更新泊位配置 |
| POST | `/api/berths/reset` | 恢复默认泊位配置 |
| GET | `/api/ships` | 获取船舶列表 |
| POST | `/api/ships` | 添加船舶 |
| DELETE | `/api/ships/<id>` | 删除船舶 |
| POST | `/api/schedule` | 运行智能调度，返回分配结果与泊位状态 |

## 说明

- 数据保存在内存中，重启服务后恢复为默认泊位与示例船舶。
- `requirements.txt` 中的 Flask-SQLAlchemy 为项目预留依赖，当前版本未使用数据库。
